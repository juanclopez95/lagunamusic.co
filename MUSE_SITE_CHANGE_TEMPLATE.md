# Muse website change request

Use this exact format when Juan requests a website edit over WhatsApp.

```text
SITE CHANGE
Request ID: WEB-YYYY-MM-DD-001
Requested by: Juan | Karen
Page: Home
Section: Hero | Works | About | Rooms | Sessions | Footer | Metadata
Current text: [exact current wording, or NONE]
Replacement text: [exact final wording]
Asset: [Drive link or NONE]
Link target: [full URL or NONE]
Reason: [one sentence]
Urgency: NORMAL | TIME-SENSITIVE
Approval: DRAFT — requires Juan/Karen approval before merge
```

Rules:

- Return finished wording, not brainstorming.
- Never change booking details, credits, release facts or links without a source.
- Never commit secrets, personal phone numbers or unpublished music files.
- Do not claim the change is live until the GitHub Pages deployment succeeds.
